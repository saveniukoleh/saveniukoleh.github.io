Огляд

Емоційна підтримка як прототип застосунку.

Resilient Mind — концепт підтримки психічного здоров’я для людей, яких зачепила війна в Україні, і для тих, хто шукає емоційну підтримку. Задум продукту включає чат-бота, запис на терапію, програми відновлення і спільноту.

Реалізований застосунок дає облікові записи через email і пароль, чат зі ШІ для авторизованих користувачів і самостійні дихальні та КПТ-вправи в браузері.

Моя роль

Самостійний розробник усього стеку.

Я спроєктував і зібрав застосунок на Vue 3 і TypeScript: архітектуру фронтенду та маршрутизацію, стан Pinia, інтеграцію Firebase Authentication і Firestore, а також викликану Cloud Function для OpenAI. Усі коміти в репозиторії — мої.

Реалізовані можливості

Що входить у прототип.

Автентифікація

Реєстрація та вхід через email і пароль у Firebase Authentication. Захищені маршрути вимагають активної сесії.

Чат-бот зі ШІ

OpenAI gpt-4o-mini через автентифіковану Cloud Function handleAIChat. Чат доступний після входу.

Самостійні вправи

Дихальні техніки та КПТ-форми (запис думок і поведінкова активація) в браузері. Прогрес не зберігається.

Архітектура

Запит від інтерфейсу до моделі OpenAI.

Vue 3 + Pinia → Firebase Cloud Function (handleAIChat) → OpenAI API (gpt-4o-mini).

Функцію handleAIChat можна викликати лише після входу через Firebase Authentication. Ключ OpenAI зберігається в секреті Firebase і не потрапляє в клієнтську збірку. Окремого сервера застосунку немає.

  1. 01

    Vue 3, TypeScript, Vue Router і Pinia — структура застосунку та стан.

  2. 02

    OpenAI на сервері через Firebase Cloud Functions.

  3. 03

    GitHub Pages, база Vite /resilient-mind/, SPA fallback для прямих посилань.

Стан проєкту

Обсяг прототипу.

Робочий прототип застосунку з автентифікацією, розмовами зі ШІ та самостійними вправами. Запис до терапевта, функції спільноти та розширені модулі відновлення лишаються незавершеними.

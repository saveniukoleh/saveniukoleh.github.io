Ein Webanwendungskonzept für zugängliche emotionale Unterstützung durch KI-gestützte Gespräche und Selbstübungen.

Überblick

Emotionale Unterstützung als Anwendungsprototyp.

Resilient Mind ist ein Konzept zur Unterstützung der psychischen Gesundheit für vom Krieg in der Ukraine Betroffene und alle, die emotionale Hilfe suchen. Die Produktvision umfasst einen KI-Chatbot, Therapiebuchung, Erholungsprogramme und eine Community.

Die umgesetzte Anwendung bietet E-Mail- und Passwort-Konten, einen KI-gestützten Chat für angemeldete Nutzer sowie Selbstübungen für Atmung und KVT im Browser.

Meine Rolle

Einzelentwickler über den gesamten Stack.

Ich habe die Vue-3- und TypeScript-Anwendung End-to-End konzipiert und gebaut: Frontend-Architektur und Routing, Pinia-State, Firebase Authentication und Firestore sowie die aufrufbare Cloud Function für OpenAI. Jeder Commit im Repository stammt von mir.

Umgesetzte Funktionen

Was im Prototyp enthalten ist.

Authentifizierung

Registrierung und Anmeldung per E-Mail und Passwort mit Firebase Authentication. Geschützte Routen erfordern eine angemeldete Sitzung.

KI-Chatbot

OpenAI gpt-4o-mini über die authentifizierte Cloud Function handleAIChat. Der Chat ist nach der Anmeldung verfügbar.

Selbstübungen

Atemübungen und KVT-Formulare (Gedankenprotokoll und Verhaltensaktivierung) im Browser. Fortschritt wird nicht gespeichert.

Architektur

Von der Oberfläche zum OpenAI-Modell.

Vue 3 + Pinia → Firebase Cloud Function (handleAIChat) → OpenAI API (gpt-4o-mini).

handleAIChat läuft nur für angemeldete Nutzer über Firebase Authentication. Der OpenAI-Schlüssel liegt in einem Firebase-Secret, nicht im Client-Bundle. Es gibt keinen separaten Anwendungsserver.

Case study

WebAR Marker Generator

A browser-based tool for creating marker-based augmented reality experiences.

Period
2021–2022
Institution
Odesa Polytechnic
Project type
Graduation project / Educational technology
  • WebAR
  • JavaScript
  • Marker Tracking
  • 3D
  • Educational Technology

Overview

Marker-based AR, opened in the browser.

WebAR Marker Generator pairs a printed marker with an image, audio, video, or 3D model. A physical object then opens as an augmented reality experience in a smartphone browser.

My role

Graduation project.

I developed the generator, coordinated the project work, and presented and defended the result.

How it works

From a QR code to the tracked result.

  1. 01

    Launch the experience from a QR code.

  2. 02

    Recognize barcode and pattern markers.

  3. 03

    Associate each marker with an image, audio, video, or 3D model.

  4. 04

    View the result as a browser-based AR experience.

Educational application

Student teams built the game pieces.

Seven teams of three students used the generator to create AR elements for educational tabletop games on operating systems: Unix process management, file systems, data locking, kernel-level operations, and process scheduling.
